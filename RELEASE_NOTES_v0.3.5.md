# Cyber Doggo v0.3.5

## English

This is a small but important hotfix for the Android build. It restores the save sharing feature, which could fail in v0.3.4 and show a `Desktop bridge unavailable` message instead of opening the Android system share sheet.

The Memory Foundation system from v0.3.4 remains unchanged. This version is mainly for fixing Android save backup sharing before wider testing.

### Downloads

- Android: `cyber-doggo-android-v0.3.5.apk`
- Windows: `cyber-doggo-windows-v0.3.5.exe`

Install the new version directly over the old one to keep your local save. Do not uninstall first unless you have already backed up your save.

### Changes

- Fixed Android save sharing.
- The Android build should now correctly open the system share sheet when exporting a save backup.
- Fixed a case where the game could incorrectly fall back to the desktop bridge and show `Desktop bridge unavailable`.
- Kept the v0.3.4 Memory Foundation cleanup system.
- Updated Android and desktop version numbers to v0.3.5.
- Marked this as an important update so older builds can remind players to update.

### Notes

Android players are strongly recommended to update to this version if they use save backup or save transfer features.

## 中文

这是赛博狗子的 v0.3.5 小型但重要的热修复版本。本版主要修复 Android 端存档分享功能。在 v0.3.4 中，点击分享/导出存档时，游戏可能没有调起 Android 系统分享面板，而是错误显示 `Desktop bridge unavailable`。

v0.3.4 的 Memory Foundation 记忆系统保持不变。本版主要是为了在继续扩大测试前，先修好 Android 存档备份分享问题。

### 下载

- Android：`cyber-doggo-android-v0.3.5.apk`
- Windows：`cyber-doggo-windows-v0.3.5.exe`

如果已经安装旧版，建议直接覆盖安装，不要先卸载。除非你已经提前备份存档，否则卸载可能会导致本地存档丢失。

### 更新内容

- 修复 Android 端存档分享功能。
- Android 版导出存档时，现在应能正确调起系统分享面板。
- 修复部分情况下游戏错误回退到桌面端 bridge，并显示 `Desktop bridge unavailable` 的问题。
- 保留 v0.3.4 的 Memory Foundation cleanup 记忆系统。
- Android 与桌面端版本号更新为 v0.3.5。
- 将本版标记为重要更新，方便旧版本玩家收到更明显的更新提醒。

### 说明

如果你使用 Android 版，并且需要备份、分享或转移存档，强烈建议更新到本版本。
