# Cyber Doggo 下载页

这里是 **Cyber Doggo（赛博狗子）** 的下载页面仓库。

赛博狗子是一款陪伴向的小游戏。你会和一只数字小狗一起生活：照顾它、阅读它写下的日记、带它外出冒险、收集物品，并一点点积累只属于你们的共同回忆。

## 下载方式

请打开本仓库对应的 GitHub Pages 页面，下载最新版本。

当前版本：

```text
v0.4.0
```

可下载版本：

- Android APK
- Windows EXE

如果你已经安装过旧版本，建议先在游戏内导出/分享备份存档，然后直接覆盖安装。除非你已经提前备份存档，否则不要先卸载旧版。

## 这次更新

v0.4.0 是一次大型底层更新，也是“三模块合龙”测试版。故事、记忆与人格三个系统现在会更紧密地互相影响：冒险和日常会产生经历，经历会进入日记、周记、回忆与冷档案，人格会从这些长期痕迹中缓慢变化，并反过来影响之后的故事。

本版本也同步修复了 Android 存档分享、进入下一天加载遮罩、普通日记的人格结算、物品修复、回忆文章结算、旧存档迁移与版本检测等问题。
