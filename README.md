# Cyber Doggo 下载页

这里是 **Cyber Doggo（赛博狗子）** 的下载页面仓库。

赛博狗子是一款和一只小狗一起生活的电子宠物游戏。你会照顾它、陪它出门、阅读它偶尔写下的日记，让普通或奇妙的小事慢慢变成你和它之间的痕迹。

我希望这个游戏能让更多人重新靠近日记。在开发它的过程中，它就已经慢慢改变了我，也让日记成为了我生活中的一部分。这些日记不一定要写得很完整，也不需要多么华丽的辞藻。有时候只是几句话，或者一天里很小的一点痕迹，就已经足够让那段时间被留下来。

## 这次更新

v0.5.0 是一次大型测试版更新。它不只是普通热修复，而是把过去几个阶段的冒险、背包、物品结算、短期人格、周记补写、测试版确认弹窗和 Story Gravity 试验整合成一个可以发布给朋友测试的版本。

主要变化包括：

- 冒险改为独立全屏流程，进入冒险前会先确认携带物品。
- 背包和物品柜结构更加清晰，普通物品和纪念品的使用意图更明确。
- 携带物品不再只是被故事提到，而会更明显影响当天冒险的氛围、地点、遭遇和故事方向。
- 冒险结束后统一结算新物品、已有物品变化和未保留物品；故事文本里明确带回的物品也会进入全文结算。
- 遇到疑似生物、有意识实体、物品归属冲突或高风险物品变化时，测试版会弹窗让玩家确认。
- 新增短期人格 `temporary`：冒险、照料和缺席会短暂影响狗子的当前状态，之后会自然衰减。
- 改进周记补写和旧存档兼容；旧存档首次打开或继续游玩时可能会补写部分周记。
- 重构了大量底层代码，为后续继续开发长故事、语言版本、存档转移和更多 AI 生成链路打基础。

## 已知问题

- 长故事、StoryThread、恐怖/克苏鲁/超展开等内容仍在后续版本继续测试。
- 普通冒险可能仍然偏日常，标题有时可能重复。
- 长期缺席期间的周记文本可能仍出现“主人回来了”这类不够准确的表述，后续版本会继续修。
- 云存档、账号系统、自动多端同步、留言区、反馈表单和完整英文版仍未完成。
