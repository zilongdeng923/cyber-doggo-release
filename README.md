# Cyber Doggo 下载页

这里是 **Cyber Doggo（赛博狗子）** 的下载页面仓库。

赛博狗子是一款和一只小狗一起生活的电子宠物游戏。你会和一只小狗一起生活，照顾它、陪它出门、阅读它偶尔写下的日记，让一些普通或奇妙的小事慢慢变成你和它之间的痕迹。

我希望这个游戏能让更多人重新靠近日记。在开发它的过程中，它就已经慢慢改变了我，也让日记成为了我生活中的一部分。
这些日记不一定要写得很完整，也不需要多么华丽的辞藻。有时候只是几句话，或者一天里很小的一点痕迹，就已经足够让那段时间被留下来。

## 下载方式

请打开本仓库对应的 GitHub Pages 页面，下载最新版本。

当前版本：

```text
v0.4.1
```

可下载版本：

如果你已经安装过旧版本，建议先在游戏内导出/分享备份存档，然后直接覆盖安装。除非你已经提前备份存档，否则不要先卸载旧版。

## 这次更新

v0.4.1 是一次大型底层更新，也是“三模块合龙”测试版。故事、记忆与人格三个系统现在会更紧密地互相影响：冒险和日常会产生经历，经历会进入日记、周记、回忆与冷档案，人格会从这些长期痕迹中缓慢变化，并反过来影响之后的故事。

本版本也同步修复了 Android 存档分享、进入下一天加载遮罩、普通日记的人格结算、物品修复、回忆文章结算、旧存档迁移与版本检测等问题。
