安装方法

  1. 手机端请选择 Android APK，电脑端请选择 Windows EXE。
  2. Android 下载完成后，点开 APK 文件并按提示安装。
  3. 如果 Android 提示“未知来源应用”，请允许当前浏览器或文件管理器安装。
  4. Windows 下载完成后，运行 EXE 安装包。如果出现安全提示，请确认来源后继续。
  5. 如果已经安装旧版，建议直接覆盖安装；除非你已经提前备份存档，否则不要先卸载旧版。

如果在微信里打不开下载，请点右上角菜单，选择“在浏览器中打开”。如果安装失败，请先确认已经允许安装未知来源应用，或检查电脑安全提示。建议在升级前先做一次存档备份。v0.3.5 可以直接覆盖安装旧版，并尽量保留原有本地存档。
