About this game

和一只小狗一起生活

你会和一只小狗一起生活，照顾它，陪它出门，和它一起度过一天又一天。它会偶尔写日记，把某些发生过的事留在自己的记忆里。

有些日子很普通，有些日子会发生小小的冒险。喂过的饭、摸过的头、带回来的旧物、写下来的日记，都会慢慢变成你和它之间的痕迹。

一开始，它可能只是屏幕里的一只小狗。后来再翻到某一篇日记，或者看到某件旧物时，你也许会想起那一天发生过什么。

我希望这个游戏能让更多人重新靠近日记。在开发它的过程中，它就已经慢慢改变了我，也让日记成为了我生活中的一部分。 这些日记不一定要写得很完整，也不需要多么华丽的辞藻。有时候只是几句话，或者一天里很小的一点痕迹，就已经足够让那段时间被留下来。

安装方法

  1. 手机端请选择 Android APK，电脑端请选择 Windows EXE。
  2. Android 下载完成后，点开 APK 文件并按提示安装。
  3. 如果 Android 提示“未知来源应用”，请允许当前浏览器或文件管理器安装。
  4. Windows 下载完成后，运行 EXE 安装包。如果出现安全提示，请确认来源后继续。
  5. 如果已经安装旧版，建议直接覆盖安装；除非你已经提前备份存档，否则不要先卸载旧版。

如果在微信里打不开下载，请点右上角菜单，选择“在浏览器中打开”。如果安装失败，请先确认已经允许安装未知来源应用，或检查电脑安全提示。建议在升级前先做一次存档备份。v0.4.1 是稳定性热修复，可以直接覆盖安装旧版，并尽量保留原有本地存档。
